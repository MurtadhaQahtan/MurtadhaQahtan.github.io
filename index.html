Layout Fixer – fix text typed in the wrong keyboard layout

A Windows 10/11 app: select text typed in the wrong layout (like ghbdtn instead of привет) and press Ctrl+Shift+L. Supports Arabic, Persian, Kurdish (Sorani), Hebrew, Russian, Ukrainian, Greek, Turkish Q and English layouts. RTL Text Fixer – Arabic, Persian, Urdu and Hebrew text for apps without RTL support

A Windows 10/11 app that connects Arabic-script letters (Arabic, Persian, Urdu, Kurdish Sorani, Pashto, Sindhi, Uyghur) and puts right-to-left text, including Hebrew and Yiddish, into visual order, so it displays correctly when pasted into Premiere Pro, After Effects, Unity, Blender and similar tools. Mic Mute Hotkey – mute your microphone in every app

A Windows 10/11 tray app: one global shortcut (default Win+Alt+A) mutes the Windows microphone itself, so calls, voice chat, browsers and games all get silence. Push-to-talk / push-to-mute, an always-on-top "Muted" indicator, 15 languages, works offline. Microsoft Store release pending.
