Layout Fixer – fix text typed in the wrong keyboard layout

A Windows 10/11 app: select text typed in the wrong layout (like ghbdtn instead of привет) and press Ctrl+Shift+L. Supports Arabic, Persian, Kurdish (Sorani), Hebrew, Russian, Ukrainian, Greek, Turkish Q and English layouts.
